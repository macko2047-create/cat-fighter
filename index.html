Two-player co-op

      
Open this page on both devices. P1 creates a game; P2 joins with the six-digit code.

      
      
      
      
      
      
Once connected, P1 closes this window and presses START. If the connection drops, reconnect, then P1 presses RESUME.

      

      Existing Wi-Fi LAN mode
      
Connect both devices to the same Wi-Fi and open the game URL provided by the computer.

      
The host controls P1; the other device controls P2. Hold and drag to move and fire automatically. Double-tap the same spot to use a bomb.

      
On the computer, run node tools/lan-server.cjs in the game folder, then open the URL shown in the terminal.
