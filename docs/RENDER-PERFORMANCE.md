# 背景辨識度與繪圖效能調整

背景保持現有島岸位置及船隻水道，首次載入時以四分之一長寬取樣再放回原尺寸，混入 44% 深藍色，降低浪花與植被的細碎對比。移除額外動態反光及每幀 200 條掃描線。原 PNG 保留，處理只在背景快取建立時進行。

飛機各圖格的投影在顯示尺寸預繪，依圖片及圖格快取；子彈和火花光暈亦預繪重用，正常每幀不再執行 shadowBlur。飛機素材、碰撞與玩法不變。光暈快取上限 24 項，飛機快取以 WeakMap 綁定原圖片。

驗證：117 個非歷史畫面雜湊回歸案例通過。瀏覽器效能腳本載入真實素材，以固定 12 敵機、175 子彈、80 粒子場景量度繪圖及強制完成 GPU 工作的成本，並擷取前後預覽。結果為壓力測試，不能當成使用者實際 FPS；首次建立快取不包含於暖機後樣本。

檔案：`artifacts/performance/measure.cjs`、`before.json`、`after.json`、`before.png`、`after.png`。腳本另驗證暖機後不新增 Canvas，及無頁面錯誤。歷史畫面雜湊保留。
