# 操作、突進敵機與循環測試版

- 觸控：戰機目標在手指上方 72 CSS px；依實際 Canvas 尺寸換算，到位不抖動，目標受戰場邊界限制。雙擊炸彈，過關倒數禁控。
- 1UP：金邊綠色寶物徽章，中央為 Cat Arcade 字體 1UP；每輪第 100 秒生成一次。
- 3-WAY：三發橫向速度 −70／0／70，向上速度 550；RAPID 保持原數值。
- 突進：每批最多一架候選，40% 啟用機率；開場及緩和波次除外。停頓 0.65 秒，警示圈與驚嘆號提示，向起衝瞬間的有效玩家位置直線衝刺。速度 500 × 當輪倍率，不持續追蹤。
- 戰敗：戰場直接顯示 GAME OVER、分數與輪數；下方 RETRY 重置首輪。
- 循環：Boss 擊破後清除戰場威脅，顯示 2.6 秒 MISSION CLEAR，保留分數、生命、武器、炸彈。存活玩家飛入下一輪；已出局玩家不自動復活；雙人等候 10 秒後，隊友仍生存時按射擊鍵或 JOIN 重新加入。每輪重新安排波次及補給。
- 難度：倍率 `1 + (輪數 - 1) × 0.05`，套用敵機／敵彈速度、敵人射擊頻率、Boss 耐久及橫移速度；警示時間保持不變。

驗收已通過：`node tests/game.test.cjs --current`、`node --test tests/charge.test.cjs`，以及 Chrome 的 Level 1、觸控、武器／版面、生命／復活、半支手掣測試。包括 175 秒實際關卡模擬、三輪流程、跨輪狀態、暫停倒數、重複擊殺保護及同幀 Boss 擊殺／碰撞優先次序。

觸控涵蓋 390×844、360×640、430×932、844×390、1440×900。GAME OVER 另檢視直向、橫向及桌面配置，按鈕無裁切。畫面預覽位於 `artifacts/gameplay-update/`。

歷史 `tests/baseline.test.cjs` 保留舊版單次勝利、3% 掉落率及繪圖雜湊，並非現版驗收；修改前已有掉落率案例失敗，未重建歷史雜湊。實體手機觸感及藍牙手掣仍需實機確認。
