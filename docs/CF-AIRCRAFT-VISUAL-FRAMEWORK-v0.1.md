# Cat Fighter — Aircraft Visual Framework v0.1

本文件是 Cat Fighter 所有飛機的共用視覺製作準則，適用於 P1、P2、鼠／鼠族戰機、重型機、Ace 與適用的 Boss。各機種可有不同輪廓、狀態、航向與行為，但必須採用同一視角、光源、Roll 語言、對齊方式與輸出管線。

## 視角與旋轉語言

- 採用俯視或微仰視的街機射擊視角。玩家戰機通常機頭朝畫面上方；敵機與 Boss 的航向依軌跡、攻擊與遭遇編排決定，不強行統一。
- **Roll** 是繞機頭至機尾的縱軸旋轉；**Yaw** 是機頭左右轉向；**Pitch** 是機頭上下傾斜。
- 玩家水平移動使用 Roll，不能以普通 Yaw 或斜轉整張 sprite 代替。敵機可視軌跡使用 Roll、Yaw、Pitch。
- Roll 須呈現不對稱翼面、透視縮短、上下翼面露出、翼寬改變、機身／座艙透視及對應明暗。不可將平面 sprite 整體旋轉成對角線。
- 正常遊戲中的 Pitch 保持克制；可用於玩家前推／後拉、敵機俯衝／爬升或 Boss 編排，並必須在俯視鏡頭下可讀。

## 共用製作管線

首選長期流程為：

`Concept Art → 3D Master Model → Fixed Camera → Fixed Global Light → Pose / Roll / Pitch → Transparent 2D Render → Sprite Sheet → Optional 2D Polish → Game Integration`

遊戲成品仍可完全為 2D。3D 母模只用來穩定機身身份、翼型、座艙、飛行員比例、Roll／Pitch、光源與 pivot；模型採低至中等複雜度、強輪廓、二戰啟發造型、toon／cel 明暗和簡化表面細節，不追求模擬級精度。

在尚未建立 3D 母模的資產階段，2D 關鍵姿態可以作為暫定產出，但必須接受下方的對齊、光源與遊戲尺寸審閱，且不得以其取代日後可重現的 3D 規格。

## 光源、投影與螺旋槳

- 所有飛機共用固定主光：**畫面右上方**；引擎控制的世界投影指向左下方。Roll／Pitch 可改變受光面，但不能移動光源。
- production sprite 使用透明背景，不能烘焙海面、地面接觸影或世界投影。引擎的共用投影系統應支援方向、偏移、不透明度、柔化、縮放與高度變化。
- 螺旋槳機共用清晰中央槳轂、簡化旋轉圓盤／動態弧與跨格穩定位置；避免縮小後成為雜訊的細槳葉。

## 飛行員、尺度與碰撞

- 貓與鼠／鼠族飛行員採大頭 Q 版。遊戲角度以頭頂／後腦、耳朵、上半身或裝備表達身份；不依賴正面表情。可透過頭形、耳朵花紋、毛色、護目鏡／頭盔、姿勢與輪廓區分。
- 同一架飛機的每格必須固定 cell、pivot、anchor、機身長度、飛行員頭部比例與中心位置。Roll／Pitch 不可造成畫面原點跳動。不同機種可使用不同 source 尺寸。
- 視覺輪廓與遊戲碰撞分離；Roll／Pitch 改變可見翼展時，hitbox 不自動改變。不要以 alpha 或渲染輪廓推導碰撞，除非後續明確設計。

## 機種狀態原則

- 玩家：Normal 為向上；左右是 Roll；上下是克制 Pitch。現行類別為 Normal、Move Left、Move Right、Move Up、Move Down、Special、Hit、Crash。
- Basic Fighter 可用 Normal、Roll Left／Right、Hit、Crash；Side Raider 使用入場航向與轉向／Roll；Heavy Bomber 可用 Normal、輕 Roll、Damaged、Crash；Ace 可額外有 Hard Roll 和 Damaged。
- 敵機航向追隨關卡編排，可為向下／向上攻擊、橫越、斜入、撤退、追擊、繞行或再入場。Boss 可因相對速度與捲動維持向上，而表現為玩家從後方追上。
- Boss 套用同一鏡頭、光源、投影與管線，但可按遭遇設計更大 source、多武器狀態、受損／弱點、進場／撤退與 phase 專屬姿態；不直接複製玩家狀態表。

## 輸出與驗收

production sprite sheet 必須透明、無烘焙投影、無標籤／格線／參考文字、光源一致、框位穩定，且身份跨格不變。所有飛機均以實際遊戲尺寸檢查：輪廓、飛行員可讀性、陣營身份、Roll／Pitch、海面／背景對比、P1／P2 區分與敵機軌跡清楚度。

核心原則：共用製作框架，不強迫共用狀態表。玩家、敵機與 Boss 共享鏡頭、Roll、光源、投影與對齊原則，同時保留角色特有的航向、狀態、輪廓、移動與戰鬥表現。
