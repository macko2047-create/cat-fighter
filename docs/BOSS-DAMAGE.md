# Final Boss 四階段損毀

保留完整入場外型，另外依最大血量比例切換四個損毀階段：

| 剩餘血量 | 外型 | 老鼠反應 |
| --- | --- | --- |
| 75% 以下 | 輕損：翼面裂痕、引擎焦黑 | 不安、冒汗 |
| 50% 以下 | 中損：引擎外殼破裂、裝甲缺口 | 睜大眼、緊張流汗 |
| 25% 以下 | 重損：兩側引擎受創、翼尖破碎 | 驚慌、大量冒汗 |
| 10% 以下 | 最終破損：機翼及引擎撕裂、核心機身保留 | 咬牙、臉紅、非常憤怒 |

子彈或炸彈跨越門檻時，加上 0.8 秒流汗與驚嘆反應。反應使用遊戲時間，暫停時停止。比例適用於 1P、2P 及循環耐久成長。

最後 10% 血量為獨立暴怒攻擊階段：每 0.32 秒射出 11 發瞄準扇形彈，基礎彈速 210（先前為 150），仍套用循環難度倍率。進入這一階段不清除敵彈、不暫停射擊，並取消尚未結束的前階段展示停火；下一次更新即可開火。前三個門檻保留清彈及 1.5 秒展示停火。

暴怒階段只承受原本 20% 傷害，最後 10% 血量約需 5 倍命中數。跨越 10% 門檻的單次傷害分段計算，門檻以上保持原傷害，以下套用減傷，子彈與炸彈一致；炸彈仍能正常清彈。沒有固定無敵倒數，足夠傷害仍可擊破。現版 `tests/game.test.cjs --current` 涵蓋跨門檻炸彈、單／雙人與循環耐久、即時開火、彈速及站樁玩家受傷。

各損毀階段亦會從翼面與引擎周圍彈出大幅誇張的金屬碎片：四階段分別 36／50／64／78 塊，向外高速飛散、翻滾、減速下墜，於約 1.7–2.5 秒內淡出。只在跨越血量門檻時觸發；炸彈一次跨過多個門檻會合併各階段的碎片。碎片不具碰撞、不消耗玩法亂數，最多保留 240 塊；暫停時凍結，過關演出仍會播放，下一輪或重開時清除。

`tests/boss-debris-browser.cjs` 已驗證四階段、同階段不重複觸發、炸彈跨階段、獨立於玩法亂數、繪圖只讀、旋轉與消失、暫停及重開／下一輪清理。實際遊戲截圖在 `artifacts/boss-debris/`。

擊破時仍立即完成本輪、計分及清除敵彈；無碰撞的暴怒殘機保留於原位置，在既有 2.6 秒過關演出最後 0.6 秒淡出。重開及下一輪清除殘機。無額外戰鬥階段。

素材使用內建 imagegen，以既有 Boss 圖作為參考。設計稿：`artifacts/boss-damage/design-sheet.png`。生成器三次輸出 RGB 棋盤背景；經使用者明確授權，改用 `tools/build-boss-damage.cjs` 從圖片外圍連通的中性背景區域去背，保留封閉機身細節。實際素材為 `assets/enemies/boss-damage-sheet.png`，1024×1024 RGBA、2×2 格。四格共用縮放，後兩格以機尾 anchor 修正垂直位置。

驗證：`node tests/game.test.cjs --current` 通過；Boss 四門檻、反應／殘機及既有素材尺寸／繪製共四個 focused 案例通過；`tests/boss-damage-browser.cjs` 驗證五種外型、暫停、炸彈擊破、下一輪清理及 file:// 素材載入。遊戲尺寸截圖與結果保存在 `artifacts/boss-damage/`。

歷史 baseline 全套仍在既有手掣 deadzone 案例失敗（預期 .2 輸入為零、目前預設 .1）；此變更未調整手掣規則。
