# 街機介面、Joy-Con 預設與雙人續玩

2026-09-09

## 畫面

1UP 採金色外框、綠色內芯及閃光，中央只放原創 Cat Arcade 字體的「1UP」。沿用現有 Canvas 寶物繪圖，不影響拾取範圍、生成時機或加命效果。

分數、輪數／波次與下方玩家資訊使用內附字體。生命改為像素貓頭加數量，炸彈獨立一行；下方資訊列高 60px。戰場保持完整 3:4 比例，Boss 血條移至上方 HUD 以下。字體可離線載入，生成來源見 `tools/build-arcade-font.py`。

## 手掣（已回退至手動校準）

使用者實機回報圖片預設令方向／按鍵混亂，已恢復之前逐一校準 P1／P2 的程式。移除裝置名稱推斷、自動軸旋轉及 Joy-Con L+R 自動拆分；舊的圖片預設儲存值不再影響輸入。方向及三個動作鍵由玩家親自設定。

預設死區維持 10%，保留之前儲存的死區與按鍵。按「返回整支手掣」可清除本次半支分配。

新增只讀 JSON 匯出與複製：包含兩位玩家的軸編號／中央值／正負方向、三個動作鍵、裝置原始讀值、自訂按鍵及死區。完成校準後，在重新整理或關閉頁面前匯出，將 JSON 附加到對話供檢查。不讀取其他 localStorage 資料，亦不推進或修改校準狀態。瀏覽器拒絕剪貼簿存取時會選取 JSON，讓玩家自行複製。

## 雙人續玩

一人用完生命後，下方由 10 秒開始倒數，期間不能加入。倒數完、隊友仍有生命時顯示 JOIN 與 FIRE 提示。可按該玩家手掣射擊鍵、鍵盤 P1 F／P2 K，或點擊 JOIN。

重新加入時有三命、三枚炸彈與初始火力；從底部飛入，到位後三秒無敵。分數及隊友狀態保留。按住射擊鍵不會在倒數結束時自動復活，必須放開再按。

暫停與過關倒數會凍結等候時間，跨輪保留尚餘倒數。全隊 GAME OVER 及單人模式不提供續玩；使用 RETRY 重開。

## 驗證

現有 `game.test.cjs --current`、`charge.test.cjs` 及 Chrome 的 Level 1、touch、bonus-layout、lives、half-controllers 檢查通過。`controller-defaults-browser.cjs` 改為手動設定回退檢查，另有 `controller-export-browser.cjs` 驗證匯出內容、只讀行為、下載及複製後備方式；`rejoin-browser.cjs` 驗證倒數、暫停、鍵盤／手掣／點擊、裝備重置與全隊死亡。

歷史 baseline 仍記錄舊版規格，未重寫。未修改 GitHub Pages 發佈副本；本次可玩版本是根目錄 `index.html` 及 `Cat-Fighter-Endless-playable.zip`。
