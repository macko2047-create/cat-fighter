# CF-CAT-HEAD-06 — 驚嚇後摺耳校準版

以使用者提供的 wireframe 及其完成模型校準 Blender 貓頭形狀。這是可編輯 3D 母模及形狀驗證，不是 imagegen 圖。

## 改善

- 頭形改為較闊的面頰、較平的頭頂及柔和下顎。
- 頭部前後深度增加至接近正面寬度的 77%；後腦保持飽滿，前額及下半面頰另有向前投射。
- 驚嚇耳以耳根為固定軸，耳身近似整體向外及後方旋轉；頭頂不再跟耳尖一起沉低。
- 正面形成接近水平的飛機耳輪廓，粉紅內耳仍可在下緣看見。
- 耳朵縮短，改成闊底圓角三角；耳根與頭部融合。
- 內耳是實際凹面，並跟隨耳朵方向。
- 移除舊版兩粒凸出嘴球；白色嘴面直接指定在頭部網格，側面沒有額外厚度。
- 增加三條白色鬍鬚、粉紅鼻及簡化嘴線。
- `Hurt • ears back` shape key 控制中彈耳仔剛性後摺；中彈狀態另有閉眼、汗滴及痛苦嘴形。

## 檔案

- `cat-head.blend`：可編輯母模，保存狀態為正常表情。
- `build_head.py`：重建模型及八張預覽。
- `front.png`、`three-quarter.png`、`side.png`、`back.png`、`top-back.png`：正常多角度。
- `hurt-front.png`、`hurt-side.png`、`hurt-back.png`：中彈多角度。
- `validation.json`：Blender 版本、網格和輸出檢查。

## 目前界線

仍是頭形階段，未製作虎紋、毛感、正式 UV、拓撲整理或 Godot 匯入。白色毛色邊界目前跟隨重建網格面，因此近看仍有輕微階梯；正式貼圖階段會用 UV 貼圖消除。眼睛與嘴形仍是簡化定位，未接入遊戲。
