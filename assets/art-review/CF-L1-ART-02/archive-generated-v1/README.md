# CF-L1-ART-02 — Normal 母稿方向審閱

狀態：已製作，待使用者核准。僅 P1 Normal／P2 Normal，未製作其他姿態，未接入正式 manifest，未修改玩法。

## 交付

- `p1-normal-master.png`、`p2-normal-master.png`：256×256 RGBA PNG，中心 anchor (128,128)，透明背景，無文字、格線或烘焙投影。
- `p1-normal-source.png`、`p2-normal-source.png`：保留生成器的高解析度原始 PNG；不是可分層的繪畫原檔。
- `gameplay-size-comparison.png`：300×150 局部比較，左 P1／右 P2；兩張圖各以 72×72 邏輯像素繪製，裁切後未放大。
- `gameplay-size-preview.png`：600×800 完整畫面，保留敵機／子彈空間參照。
- `metrics.json`：輸出尺寸記錄；`prompts.txt`：完整生成與修正提示詞。

採用內建 imagegen。P2 初稿的棋盤背景經 imagegen 修正為真實 alpha。之後以 Sharp 等比例縮放、加透明留白輸出母格；未以程式重畫美術。`build-preview.cjs` 呼叫現有 world／renderer，僅注入獨立審閱用圖片資料，並使用固定場景。這是實際繪圖程式的靜態合成，不是遊玩測試截圖。

## 尺度與可讀性檢查

兩圖 alpha 範圍均在 [32,224) 安全區內；包含淡透明像素的輸出範圍分別約 180×190、183×190 px，採同一中心原點。遊戲整格均為 72×72，可見機體約 50×50；審閱時應以 PNG 原始尺寸觀看，避免圖片檢視器自動放大。

1. P1 銀紅與 P2 深藍／象牙白在海面上可區分。
2. P2 可由奶油色翼部徽記、翼端分區、白色頭部及槳影辨識，但深藍機翼下緣的對比偏弱。
3. 兩機目視尺度接近，頭部沒有壓過戰機輪廓；仍有充足空間呈現敵機與子彈。
4. 槳影在小尺寸可見，但目前偏向亮色小圓盤，後續精修可再降低不透明感。
5. P2 黑耳在 256px 母稿清楚，在 72px 整格只剩少量像素，尚不能視為穩定可讀的識別特徵。
6. P2 翼型與 P1 有差異，但海鷗翼特徵在小尺寸仍偏細微。

## 核准前建議

建議方向可供審閱，但尚不宣稱全部美術條件已通過：若需下一輪 Normal 精修，優先略放大兩機頭部（維持相近比例），強化 P2 黑耳與海鷗翼折角；在 P2 右上受光翼緣增加窄幅象牙白／明度分離，不整架提亮。兩機都有右上亮面，但部分機身高光偏中央，若嚴格鎖定單一右上光源，應再統一高光位置。保持現有 72×72 顯示尺寸及安全區。

目前可核准的是美術方向；尚待使用者決定是否接受或先精修。核准 Normal 前，不產出 Roll／Pitch／Special／Hit／Crash。
