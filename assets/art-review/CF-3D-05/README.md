# CF-3D-05 — P1 參考母模重建第一版

用途：以 CF-L1-ART-02 的 P1 外觀重建實體，提供翻滾、俯仰、遮擋與自身明暗參考。這是程式建立的真實 3D 網格與 Godot 渲染，沒有使用 imagegen。未覆蓋 CF-3D-04、原插畫或遊戲素材。

## 開啟與輸出

- 在 Godot 匯入 `project.godot`，執行即可進入檢視場景。
- 拖曳滑鼠旋轉鏡頭、滾輪縮放、R 重設鏡頭；1 Normal、2 左翻滾、3 右翻滾、4 仰起、5 俯下。
- `p1-editable-master.tscn` 是已展開的網格零件，可在 Godot 編輯器逐件選取與修改；不用先執行建立腳本。重新渲染會從程式重新匯出此檔，所以手動修改請另存場景。
- `p1_master.tscn` 是依程式即時建立的版本；`p1_production_master.gd` 為可重現來源。
- `p1-reference-comparison.png`：左 ART-02、中 CF-3D-04、右 CF-3D-05。各自裁去透明邊界並等比例放入比較格，只比較外觀，非 pivot 對齊驗收。
- `p1-production-review.png`：上排 Normal／左 Roll／右 Roll，下排 Pitch Up／Pitch Down。
- 五張單姿態 PNG：1024×1024 RGBA。另有五格 72px 的 `p1-gameplay-size-preview.png`。

重新渲染：

```zsh
'/Applications/Godot.app/Contents/MacOS/Godot' --rendering-method gl_compatibility --path assets/art-review/CF-3D-05 --script res://render_p1_production.gd
```

## 本版重建內容

連續截面機身與紅色引擎罩、帶厚度的漸縮翼面與紅翼尖、尾翼、座艙圍邊與玻璃、皮座椅、大頭橘貓與實體耳朵、貼合頭部的虎斑、鬍鬚、沿後機身延伸的條紋尾巴、翼面與機身徽章、機槍、面板接縫、鉚釘，以及連接鼻端的槳軸與半透明槳盤。

修正原始球體隱含尺寸造成的接駁問題；新截面網格使用明確法線與 Godot 順時針正面順序，左右翼分別處理方向。所有零件共用一個模型，沒有姿態專用幾何或逐格重畫。

## 固定渲染設定

此版為新的比例與鏡頭基準，並非沿用 CF-3D-04 的完全相同捕捉設定。

- 前方 -Z，上方 +Y；根節點尺度 `(1,1,1.12)`，pivot `(0,0,0)`。
- 正交鏡頭 `(0,8,3.6)`、看向原點、size 5.7。
- 主光旋轉 `(-52,36,0)`、色 `fff1d4`、energy 0.95；環境光 `6f8293`、energy 0.45。每個姿態固定不變。
- Roll 為 Z ±28°；Pitch 為 X ±10°；Yaw 固定 0。
- 無烘焙世界投影。檢視場景可自由轉鏡頭，但批次輸出始終重設固定鏡頭。

## 驗證與限制

Godot 4.7.2 圖形模式成功輸出五姿態，`validation.json` 記錄尺寸、alpha、非透明邊界與角度；確認透明角落與無裁邊。檢視場景亦通過 headless 載入；該環境出現系統 CA 憑證提示，但沒有場景或腳本錯誤。已目視檢查 Normal、翻滾審閱表、原稿比較及 72px 預覽；互動控制尚未逐項人工操作驗收。

**尚未達到 ART-02 高還原母模要求。** 貓頭仍偏圓，耳形與原稿不同；翼尖仍有多邊形感；槳盤太簡化；原稿的毛髮、描邊、金屬反射層次與更多面板細節尚未重建。機頭長度、座艙位置與機身／翼面比例仍需按 Normal 比較校準。虎斑和徽章是表面網格，局部仍需精修貼合。最小畫布邊距約 11px，尚未套用正式 256px 格的安全留白規格。

本版改善了結構連續性和跨姿態一致性，但不能視為最終美術或已核准的精準陰影參考。未接入遊戲、未製作 P2、未提交 Git（此工作目錄沒有 Git 儲存庫）。
